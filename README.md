# 🌤️ Weather Forecast App

> A responsive, API-free weather dashboard built with HTML5, Tailwind CSS, and Vanilla JavaScript.

## Features
- Search for a city's weather
- Shows temperature, condition, humidity, and wind speed
- Weather icons for sunny, rainy, cloudy, snowy, stormy, and partly cloudy conditions
- Friendly error messages for empty input and unknown cities
- Responsive layout for phones, tablets, and desktops
- Recent searches saved with localStorage (last 5 cities)
- Today's date shown dynamically

## Available Cities
Lagos, London, Tokyo, Abuja, Paris, Moscow, Miami

## How to Run
1. Clone the repository or download the files.
2. Open `index.html` in any modern browser.

## Technologies
- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript
- localStorage
